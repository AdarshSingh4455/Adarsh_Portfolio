ERP SaaS Platform

Multi-module administrative cloud solution built for institutions to track attendance, examinations, libraries, and users.

Project Overview

The ERP SaaS Platform is an enterprise-grade cloud application designed to streamline institutional operations, digitize records management, and simplify user workflows. Architected as a multi-module system, it offers unique access dashboards for administrators, staff, students, and parents.

With absolute security in mind, the platform uses JSON Web Token (JWT) authentications and custom database schema rules to implement rigid Role-Based Access Controls (RBAC), ensuring users can only read, write, or modify records within their authorized scope.

Core Modules & Features

  • Student & Parent Portals: Personalized profiles tracking progress, invoices, reports, and notice bulletins.
  • Attendance Management: Direct teacher check-ins, automated warning emails, and statistical monthly tallies.
  • Examination Module: Grade sheet generators, online test schedulers, marks registers, and performance analytics.
  • Library Management: Dynamic log files tracking books checked out, return alarms, and fine accounting.
  • Notice Board System: Global alerts feed, custom newsletters, and class-level announcements notifications.
  • Role-Based Access Control (RBAC): Granular permissions managing editor, view-only, and super-admin rights.
  • RESTful API Integration: High-performance server endpoints handling data transmission cleanly.

Platform Architecture

Designed using a decoupled monolithic pattern, the platform connects a React-based frontend dashboard with a Node.js & Express REST API server. Supabase and PostgreSQL handle relational database tables, utilizing foreign key cascades and triggers for database calculations.

Storage services are integrated to support file uploads for study materials, profile avatars, and examination papers securely.
