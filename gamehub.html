GameHub SaaS Platform

Multi-game browser gaming platform with user profiles, XP progression tracking, and achievement unlocks.

Project Overview

GameHub is a comprehensive web-based gaming platform that hosts interactive browser games, provides player accounts, and monitors performance statistics. It was designed to explore real-time data syncs, gamification systems, and smooth reactive UIs for web gamers.

The platform operates on a central authentication gate where players can register, sign in to track their scores, unlock virtual badges, and compare statistics on global leaderboards.

Core Platform Features

  • Multiple Games Library: Integrated browser games including Hand Cricket (multiplayer number battle), Scribble, Dumb Charades, Tic-Tac-Toe, Word Wizard, and Rock Paper Scissors.
  • XP Progression System: Earn Experience Points (XP) for playing, winning matches, and maintaining daily logins.
  • Badges & Achievements: Unlocked badges displayed on user profiles indicating milestones reached.
  • Responsive Gaming Dashboard: Unified sidebar control panel monitoring player stats, streaks, and unlocked nodes.
  • Mobile Gameplay support: Clean navigation bars and layout adjustments for playing on handheld viewports.
  • Database Integration: PostgreSQL tables tracking user profiles, credentials, scores, and active logs.
